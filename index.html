Access Denied / Not Loading
Your Apps Script is not deployed as a public web app. This is the most common cause.
Fix in 60 seconds:
1. Open your Apps Script project
2. Top-right → Deploy → Manage deployments
3. Click pencil ✏ to edit
4. “Who has access” → set to Anyone
5. Click Deploy → copy the new /exec URL
6. Paste it in Admin → edit this code’s URL

6. Click Deploy → copy the /exec URL
7. Paste that URL in Admin for that code
